# Claude Haiku 4.5

> [[Anthropic]] 三款模型中回應最快、單次成本最低的模型。定位「以最經濟價格取得接近前沿效能」。

## 規格
| 項目 | 值 |
|---|---|
| 上下文窗口 | 200K tokens |
| 最大輸出 | 64K tokens |
| 輸入定價 | US$1 / MTok |
| 輸出定價 | US$5 / MTok |
| [[延伸思考]] | ✅ |
| [[自適應思考]] | ❌ |

## 定位
性價比優先。**沒有 [[自適應思考]]**（這可能就是它便宜的原因之一），但仍支援基本 [[延伸思考]]。

## 適用情境
- 即時應用與低延遲互動介面
- 大規模、重複性的批次任務
- 成本敏感的初期原型開發
- 多 agent 系統中的子任務節點
- 快速迭代的測試階段

## 推薦策略（來自官方）
**先用 Haiku 跑遍日常任務**，遇到「不夠用」的環節再針對性升級到 [[Claude_Sonnet_4.6]] 或 [[Claude_Opus_4.6]]。避免因選錯模型帶來的高成本與低效率。

## 與其他模型的差別
- 比 [[Claude_Opus_4.6]]：少了 [[自適應思考]]、context 小 5 倍、輸出小 2 倍、**輸出成本便宜 5 倍**
- 比 [[Claude_Sonnet_4.6]]：少了 [[自適應思考]]、context 小 5 倍、輸出成本便宜 3 倍
