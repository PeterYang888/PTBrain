# Grok 4.5

> [[xAI]] 2026-07 發布的旗艦模型：主打軟體工程自主代理（agentic）能力與每秒最高 80 tokens 的生成速度，直接對標 [[Claude_Code]] 與 [[OpenAI_Codex]]。

## 關鍵事實（來自 [[2026-07-18_grok_4_5_發布]]，影片實測口述）
- **定位**：專為知識工作與複雜編碼任務打造，重點訓練真實工程項目中的長期推理能力
- **速度**：每秒最高 80 tokens
- **辦公自動化**：原生生成 .xlsx（含複雜公式）/ .pptx / .docx
- **CLI**：`pip` 安裝（Windows/Linux）；輸入 `grok` 標準模式、`agent` 代理模式；xAI 或 Google 帳號授權
- **Agent 模式**：自主聯網研究（至少讀 50 網頁），導出 PDF / Markdown / 含 GitHub 地址的表格
- **實測案例**：UE5 搭建 Cyberpunk 街道場景——千萬級 Token、半小時、API 成本約 12 美金；10 分鐘生成含物理引擎與 3 關卡的憤怒鳥克隆
