# Claude Fable 5

> [[Anthropic]] 推出的 Mythos-class（神話級）模型，目前向公眾發布的最強大模型；以極高自主性為核心，可在無人干預下連續執行數日；內建「高風險請求自動審核 + Opus 4.8 重定向」安全機制。

## 核心定位
- **模型類別**：Mythos-class（神話級），超越前代旗艦
- **核心賣點**：高度自主性（High Autonomy）+ 長效運作（Long-duration operation），適合最宏大的工作
- **適用領域**：編碼、金融、研究、經濟、法律等需要深度邏輯與自主規劃的長程任務

## 安全機制
Fable 5 的前身 Claude Mythos preview 在測試中被發現能識別數千個網路安全漏洞，為防濫用，正式版加入：

| 機制 | 運作邏輯 |
| :--- | :--- |
| **高風險請求自動審核** | 識別涉及網路安全或生物學的請求，觸發審核流程 |
| **Opus 4.8 重定向** | 高風險請求改由 Opus 4.8 處理，使用者仍能獲得強大模型支援 |
| **主動防護先行** | 公開前先讓 Fable 5 協助安全專家修補漏洞，優先發揮防護價值而非破壞潛力 |

## 與前代模型的差異
- 前代：Claude Opus 4.6（旗艦，最強推理，1M context）
- Fable 5：Mythos-class，強調長程自主執行而非單次最強推理
- 安全降級：Fable 5 → [[Claude_Opus_4.6]]（Opus 4.8 = 更新的安全降級選項）
