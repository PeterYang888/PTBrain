# Replit

> 雲端開發平台，提供多 Agent 並行編碼能力；其協作模式類比 Git 分支與合併。

## 關鍵事實（來自 [[2026-07-10_agent_teams_協作模式]]）
- **Replit Pro**：支援同時並行運行最多 **10 個** agents
- **一般方案**：同時運行 **2 個** agents
- **Credits 定價範例**：購買 $500 credits 優惠價為 $440
- 多 Agent 協作模式類比 **Git branches**：各 agent 於分支工作，最後 try to merge back to main

## 與其他頁的關係
- 屬於 [[Agent_Teams]] 的商用實作之一
- 對比 [[Claude_Code]] 的 [[Dynamic_Workflows]]（16 並行 / 上限 1000 個 agent），Replit 並行度低但有明確的分支合併語意
