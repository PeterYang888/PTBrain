# LLM 原理

> 從一顆[[感知機]]到 ChatGPT 的完整技術主線樞紐頁。串起 PTBrain 中所有深度學習與大型語言模型的**原理層**頁面（不含工具與工作流，那條線在 [[Agentic_Workflow]]）。

## 主線：一條由下往上的階梯

### 第 0 層 — 為什麼這件事可行
- [[聯結主義]] — 從資料學特徵，對立於符號主義的人工規則。這是整條路線的哲學前提
- [[萬能逼近定理]] — 神經元夠多 ＋ 非線性，即可逼近任何曲線。它保證「能表達」，不保證「找得到」
- [[泛化]] — 舉一反三；擬合底層規律而非死記樣本。這才是智慧的判準

### 第 1 層 — 最小單元與訓練機制
- [[感知機]] — 加權求和超過閾值就啟動；1957 年起點，1969 年 XOR 困境
- [[神經網路]] — 多層堆疊；權重解決「量綱不可公度」，隱藏層負責升維與抽象
- [[激活函數]] — 非線性的來源。沒有它，疊再多層仍等價於一條直線
- [[梯度下降]] — 霧中下山，沿梯度反方向走；步長由學習率 $\eta$ 決定
- [[反向傳播]] — 鏈式法則把誤差層層回傳；1986 年的關鍵突破，代價是梯度消失

### 第 1.5 層 — Transformer 之前：NLP 的序列建模嘗試
Transformer 不是憑空出現的，它是為了解決前幾代序列建模方法的具體瓶頸而生（見 [[2026-08-22_詞向量到transformer_nlp演進]]）：

- [[N-gram]] — 純統計詞語組合頻率；組合爆炸 + 符號孤立，無法泛化到沒見過的新組合
- [[詞向量]] — 把詞轉成高維語義座標，解決符號孤立問題，讓模型能算「兩個詞有多像」
- [[前饋網路]] — 能學比統計更複雜的規律，但輸入窗口長度固定死，超出窗口等於不存在
- [[RNN]] — 用隱藏狀態讀取任意長度句子，但距離越遠舊資訊越模糊（長期依賴問題）
- [[LSTM]] — 加細胞狀態 + 三道門解決遺忘問題，但仍是**逐字順序計算，無法並行**

這條演進線的終點瓶頸——LSTM 解決了「記憶」卻沒解決「並行」——才是 Transformer 注意力機制真正的登場動機，而非單純嫌 LSTM 記性不好。

### 第 2 層 — Transformer 架構
- [[Transformer]] — 2017《Attention Is All You Need》；當前所有 LLM 的底層框架
- [[注意力機制]] — QKV 匹配 ＋ Softmax 權重；Token 之間交換資訊
- [[位置編碼]] — 注意力沒有順序感，必須額外注入；RoPE 與 Lost in the Middle
- [[MoE]] — 稀疏激活；用總參數買容量，用激活參數付成本

一次前向運算的完整流程見 [[Transformer]]：Tokenization → Embedding → 位置編碼 → 注意力 → FFN → 殘差流 → 下一個 Token。

### 第 3 層 — 從基礎模型到助理
基礎模型只會做一件事：**預測下一個 Token**。要變成能對話、能推理的助理，靠的是後續三階段（見 [[2026-05-24_karpathy_deep_dive_llms]]）：

| 階段 | 產出 | PTBrain 頁面 |
|---|---|---|
| 預訓練（Pre-training） | 基礎模型：知識 | TODO — 尚無專頁 |
| 指令微調（SFT） | 助理模型：對話行為 | TODO — 尚無專頁 |
| 強化學習 | 推理模型：思考能力 | [[RLHF]]（人類偏好）／[[推理模型]]（可驗證答案） |

- [[RLHF]] — 以人類偏好訓獎勵模型，用於無法自動驗證的領域
- [[推理模型]] — 大規模 RL 換來自我檢查與回溯；更多 Token ＝ 更多思考時間
- [[AI_Alignment]] · [[合憲_AI]] — 對齊研究與 Anthropic 的改良路線

### 第 4 層 — 能力邊界
- [[對抗樣本]] — 微小噪點讓熊貓變烏龜；[[泛化]]的另一面
- **Token 化的副作用** — 拼寫與計數任務出錯（草莓數不出 R），因為模型看的是 Token 不是字元
- **反向偏誤（Reversal Curse）** — 知道「A 的母親是 B」，答不出「B 的兒子是誰」
- **瑞士起司能力模型** — 能解博士級問題，卻答錯 9.11 與 9.9 誰大

## 旁支：路線之爭
LLM 路線不是唯一解。[[Yann_LeCun]] 主張純語言模型是死胡同：

- [[AGI]] — 兩大路線的分歧點
- [[世界模型]] — AI 必須能預測「行動後的物理後果」，而非只生成下一個 Token
- [[JEPA]] — 預測抽象嵌入而非像素，是世界模型目前最接近的實作

對照表見 [[世界模型]]：LLM 輸出下一個 token／世界模型輸出下一個抽象狀態向量。

## 旁支：另一種生成範式
- [[擴散模型]] — 逐步去噪；文生圖主流。與 LLM 的自迴歸生成是兩條不同路線
- [[VAE]] · [[CLIP]] · [[CFG]] — 潛在空間、圖文對齊、引導機制
- 交會點：擴散模型用 **Cross-Attention** 注入文字條件，FLUX 的 DiT 直接把 [[Transformer]] 用進擴散——兩條路線在架構層是相通的

## 五位主講者的理解階梯
同一套知識，五種切入深度。想補課時按此順序：

| 順序 | 來源 | 切入點 |
|---|---|---|
| 0 | [[軒轅]] | Transformer **之前**：N-gram → 詞向量 → RNN → LSTM，鋪陳「為什麼需要 Transformer」 |
| 1 | [[王木頭]] | 從二維分類逐步推導：**為什麼**需要權重、非線性、隱藏層 |
| 2 | [[漫士]] | 史觀 ＋「智慧即函數」：1943 到今天怎麼走過來的 |
| 3 | [[大飛]] | [[Transformer]] 內部：逐組件拆解一次前向運算 |
| 4 | [[Andrej_Karpathy]] | 訓練三階段 ＋ 工程現實：成本、資料量、能力邊界 |

有趣的交叉驗證：王木頭與漫士**獨立**提出了同一個[[梯度下降]]比喻（「高山迷霧」vs「大霧中下山」），可見那是該概念的標準直覺。

## 已知缺口（TODO）
這些概念在多份來源中被反覆討論，但 PTBrain 尚無專頁：

- **Tokenization** — Token 是 LLM 的基本原子；GPT-4 約 10 萬字典；拼寫／計數錯誤的根源
- **預訓練（Pre-training）** — 三階段之首；Fine-web 約 44TB／15 兆 Token；「網路的有損壓縮」
- **指令微調（SFT）** — 三階段之二，[[RLHF]] 頁引用但無頁
- **Scaling Laws** — 表現是參數量 N 與資料量 D 的平滑函數，LLM 路線的根本假設
- **Context Window** — AI 的工作記憶／RAM；與[[位置編碼]]的 Lost in the Middle 是同一問題的兩面
