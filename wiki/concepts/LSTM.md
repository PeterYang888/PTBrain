# LSTM（長短期記憶網路，Long Short-Term Memory）

> 對 [[RNN]] 的改造：在原本的隱藏狀態之外，增加一條專門傳遞重要長期資訊的「細胞狀態（Cell State）」通道，並用三道門控制資訊的保留、寫入與輸出，解決 RNN 的長期依賴問題。

## 詳細說明
LSTM 讓模型自己學會「什麼時候該記、什麼時候該忘、什麼時候該拿出來用」，而不是把所有新資訊一股腦覆蓋進隱藏狀態。三道門背後都是可訓練的參數，透過訓練資料中的預測誤差反向傳播來學習（見 [[2026-08-22_詞向量到transformer_nlp演進]]）。

## 關鍵特徵 / 組成
- **細胞狀態（Cell State）**：專門的長期記憶「VIP 通道」，儘量少做複雜修改，讓重要資訊能穩定地一路往後傳
- **遺忘門（Forget Gate）**：決定之前保存的每部分資訊還要留下多少，刪除已經沒用的舊資訊
- **輸入門（Input Gate）**：決定當前這個 Token 帶來的新資訊，有多少值得寫進長期記憶
- **輸出門（Output Gate）**：決定當前這一刻，長期記憶裡有哪些資訊該被拿出來使用
- 三道門的輸出都是 0 到 1 之間的數值，數值大小即控制資訊流動的比例

## 與其他概念的差別
- 跟 [[RNN]] 的差別：LSTM 解決了 RNN「容易遺忘長距離資訊」的問題，是 RNN 的直接改良版
- 跟 [[Transformer]] 的差別：LSTM 雖解決了遺忘問題，卻**沒有解決順序計算的效率瓶頸**——模型必須先讀完前一個 Token 才能處理下一個，無法大規模並行運算；這正是 Transformer 誕生的真正動機，而非單純「記憶力不夠」

## 應用 / 實例
- 在很長一段時間裡是 NLP 的主力模型：機器翻譯、語音辨識、文字生成都大量使用過 LSTM
- 影片主講者 [[軒轅]] 特別點出：兩個距離很遠的 Token 之間，即使有 Cell State，資訊仍要經過中間每一步逐步傳遞——這個限制直接引出下一集的注意力機制（讓任一 Token 都能直接查看任何位置的其他 Token）
