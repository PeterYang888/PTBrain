# RNN（循環神經網路，Recurrent Neural Network）

> 在 [[前饋網路]] 的基礎上增加一份可以不斷向後傳遞的「隱藏狀態（Hidden State）」，讓模型能依序讀取任意長度的句子，而不必事先規定輸入窗口大小。

## 詳細說明
RNN 解決了前饋網路「固定窗口」的限制：句子有多長，模型就讀多長。隱藏狀態本質上也是一個向量，可理解為模型的「記憶」，每讀一個新 Token 就更新一次，把前面讀過的內容持續壓縮傳遞到後面（見 [[2026-08-22_詞向量到transformer_nlp演進]]）。

## 關鍵特徵 / 組成
- **隱藏狀態（Hidden State）**：一組不斷更新的向量，壓縮表示模型目前為止讀過的內容
- **長期依賴問題（Long-term Dependency Problem）**：隱藏狀態的容量固定，新資訊不斷湧入會覆蓋舊資訊，傳遞距離越長、最早的資訊就越模糊——RNN 容易記住鄰近內容，卻很難穩定記住幾十甚至幾百個 Token 之前的資訊
- **訓練困難**：某個早期資訊重不重要，往往要等很多 Token 之後預測出錯才會知道，誤差反向傳播回去時訊號容易衰減，導致模型「不僅容易忘，甚至很難學會該記什麼」

## 與其他概念的差別
- 跟 [[前饋網路]] 的差別：FFN 只能看固定長度窗口，RNN 靠隱藏狀態讀取任意長度——是關鍵的一步升級
- 跟 [[LSTM]] 的差別：LSTM 是針對 RNN「長期依賴問題」的直接改造，加了一條專門的長期記憶通道與門控機制

## 應用 / 實例
- 曾廣泛用於機器翻譯、語音辨識、文字生成等序列任務，直到 [[Transformer]] 出現後才逐漸被取代
