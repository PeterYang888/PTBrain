# 激活函數（Activation Function）

> 加在神經元輸出上的非線性變換。它是[[神經網路]]能表達複雜曲線的前提——沒有它，疊再多層都等價於一條直線。

## 為什麼非線性是必要的
線性疊加仍為線性。少了激活函數，多層網路的表達力不會超過單層，[[萬能逼近定理]]也就不成立。

## 常見類型
| 函數 | 公式／特性 | 用途 |
|---|---|---|
| **Sigmoid** | $\sigma(z) = \frac{1}{1+e^{-z}}$，壓到 $(0,1)$ | 二分類機率輸出 |
| **Softmax** | Sigmoid 的多分類版，輸出機率歸一化 | 多分類輸出層 |
| **Tanh** | 壓到 $(-1,1)$ | 早期隱藏層 |
| **ReLU** | 負值歸零，計算簡單 | 深度網路主流起點 |
| **GELU** | ReLU 的平滑版 | Transformer 早期 |
| **SwiGLU** | 門控線性單元變體 | 現代 LLM 主流 |

## 兩條演進線
- **深度學習通用**：Sigmoid／Tanh → **ReLU**（緩解梯度消失、計算便宜）
- **[[Transformer]] 內部**：ReLU → GELU → **SwiGLU**

## 與梯度消失的關係
Sigmoid 在輸入絕對值大時梯度趨近 0，深層網路做[[反向傳播]]時梯度連乘會急速衰減——這是**梯度消失（Gradient Vanishing）**的主因之一，也是 ReLU 取而代之的動機。

## 與其他概念的關係
- 是[[萬能逼近定理]]成立的必要條件
- 影響[[反向傳播]]的梯度傳遞品質
- 在 [[Transformer]] 中位於 FFN 內部，與[[注意力機制]]層正交
