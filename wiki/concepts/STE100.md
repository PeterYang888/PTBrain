# STE100

> Simplify Technical English，歐洲航太工業數十年前制定的寫作標準：句子短、一句一動作、一詞一意。

## 詳細說明
制定背景是飛機維修手冊若寫得讓人看不懂，維修人員錯一步可能出人命，因此規定寫作必須極度精確、無歧義。這套成熟解法被拿來管理 AI（尤其是高階模型）的說話方式，因為「技術文件寫到沒人看得懂」是工程界早就解決過的老問題，不是 AI 時代才出現的新麻煩。

## 關鍵特徵 / 組成
- 句子要短
- 一句話只講一個動作
- 措辭固定、一個詞只能有一個意思

## 與其他概念的差別
- 跟 [[Output_Style]] 的關係：STE100 是可以寫進 output style 規則裡的其中一種句構標準（例如「STE100 簡報版」風格），本身不是 Claude Code 的功能

## 應用 / 實例
- [[Gary_Chen]] 團隊把 STE100 用在給 Vibe Coder / PM 的自訂 output style
- [[Matt_Pocock]] 的「W」skill 內部規則也採用 STE100 標準＋專案詞彙
