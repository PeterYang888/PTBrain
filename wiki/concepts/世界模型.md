# 世界模型（World Models）

> [[Yann_LeCun]] 倡導的 AI 架構理念：AI 必須在內部建立一套能預測「行動後物理後果」的表示系統，而非只是生成文字或像素；是 [[JEPA]] 路線的核心哲學。

## 詳細說明
世界模型的核心問題：**一個真正智慧的系統，必須能在採取行動前預見後果**。

LLM 沒有世界模型。它們根據當前上下文生成下一個 token，無法在採取行動前「在腦中模擬後果」。這就像閉著眼睛開車，全憑感覺打方向盤，出了岔子也圓不回來。

世界模型的能力：
- 給定「目標狀態」和「當前狀態」，在腦中模擬不同動作的後果
- 選出最優的動作路徑（不必把所有可能性畫出來）
- 類比：打台球前在腦中模擬母球軌跡，不是算每一帧像素，而是算抽象因果

## 關鍵特徵
- **物理直覺**：能預測行動的物理後果（力、重力、碰撞）
- **因果推理**：不只是相關性，是因果關係的內部模型
- **分層規劃**（Layer World Model）：
  - 高層：長期宏觀策略（從北京到上海，決定走高速）
  - 中層：中期規劃（服務區加油）
  - 低層：短期執行（踩油門打方向盤）

## 與 LLM 的根本差別
| | LLM | 世界模型 |
|---|---|---|
| 輸入 | 文字序列 | 任意感知（圖像、視頻、物理狀態） |
| 輸出 | 下一個 token | 下一個抽象狀態向量 |
| 維度 | 有限詞彙表 | 物理空間（無限可能） |
| 應用 | 語言理解/生成 | 機器人控制、物理規劃 |

## 實現方式
[[JEPA]]（聯合嵌入預測架構）是目前最接近世界模型的技術路線。

## 爭議
- LeCun：LLM 是死胡同，世界模型才是 AGI 之路
- OpenAI / LLM 陣營：Scale is all you need，LLM 加上 agent 機制可以實現世界模型的功能
- 目前：兩條路線都在發展，結果未定
