# VAE（變分自編碼器）

> Variational Autoencoder；一種生成模型架構，將圖像壓縮到結構化的潛在空間（Latent Space），再重建回像素空間；是現代擴散模型（如 Stable Diffusion）的核心組件，提供低維、平滑的潛在空間供擴散過程運作。

## 與普通 Autoencoder 的差別
| | Autoencoder | VAE |
|---|---|---|
| 潛在表示 | 點映射（deterministic） | 分布映射（μ, σ²） |
| 潛在空間 | 任意分布，無結構 | 強制近似標準正態 N(0, I) |
| 生成能力 | 差（空間不連續） | 好（可從 N(0,I) 採樣） |
| 重建質量 | 清晰 | 模糊（需額外損失修正） |

## 損失函數（ELBO）
VAE 損失 = **重建損失** + **正則化損失（KL 散度）**

- **重建損失**：L2（像素級別比較），鼓勵 X̂ ≈ X
- **KL 散度**：D_KL(q_φ(z|x) || p(z))，強制潛在分布貼近標準正態，讓潛在空間有結構

係數 λ 控制兩者平衡：λ 過大 → posterior collapse（不看輸入只輸出固定值）

## 模糊問題與解決策略
**問題根因**：像素 L2 在不確定性下取平均 → 模糊輸出

**解法 1 — 感知損失（LPIPS）**：
- 比較特徵圖（feature maps）而非原始像素
- 空間不變性強，容忍小幅位移，更接近人類感知相似度

**解法 2 — 對抗損失（GAN）**：
- 判別器區分解碼器輸出與真實圖像
- 迫使解碼器生成更真實、細節更豐富的圖像

## 在擴散模型中的角色
- **訓練**：先訓練 VAE，再在其潛在空間訓練擴散/流匹配模型
- **推理**：從潛在空間 Gaussian 採樣 → ODE 求解 → VAE 解碼器重建像素
- **壓縮比（spatial compression ratio）**：通常約 8（1024×1024 圖像 → 128×128 潛在向量）
- **編碼器 vs 解碼器**：解碼器比編碼器大（負責重建感知細節，而編碼器只需捕捉語義）

## 應用
- Stable Diffusion（LDM）、FLUX、SD3 等主流文生圖模型的基礎組件
