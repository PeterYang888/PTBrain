# 工具無關性（Tool Agnosticism）

> 把開發成果建構成「任何 AI 都能讀取的智能系統」，而非綁定單一工具的專案，以避免被單一模型/廠商鎖定。

## 詳細說明
專案的核心知識（docs、reference、context 資料夾、Skills）應該是通用資產；切換 AI 工具時只需新增對應工具的介面檔，不必重建大腦。這讓開發者能在不同模型間取長補短，並在某工具「越用越笨」或卡關時無痛接手。

## 關鍵實踐（Claude Code ↔ Codex）
- **共享層**：docs / reference / context 通用，Skills 格式兩邊相同可直接複製
- **介面差異**：Agents 在 [[Claude_Code]] 用 `.md`、在 [[OpenAI_Codex]] 用 `.toml`（轉移時建 `.agent` 資料夾）
- **同步規則**：在 `CLAUDE.md` / `agent.md` 寫規則，讓兩套工具同步抓最新 Skill 與設定
- **雙引擎策略**：Claude Code 做開發/風格/快速 Debug；Codex 做複雜後端/深度推理（Low/Medium/High）

## 與其他概念的關係
- 是 [[定義任務]]、[[Context_工程]] 能跨工具複用的前提
- 支撐 [[Loop_Engineering]] 的 Maker/Tracker 角色分離（不同工具扮不同角色）
