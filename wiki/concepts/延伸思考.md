# 延伸思考 / extended thinking

> [[Anthropic]] [[Claude]] 的推理增強功能。模型在回答前保留 token 做內部推理，再產出最終答案。

## 支援範圍（截至 2026-04）
三款現役模型**全部支援**：
- [[Claude_Opus_4.6]] ✅
- [[Claude_Sonnet_4.6]] ✅
- [[Claude_Haiku_4.5]] ✅

## 與 [[自適應思考]] 的差別
- **延伸思考**：把固定（或使用者指定）的思考預算讓模型「先想再答」
- **[[自適應思考]]**：模型根據問題複雜度**動態調整**思考深度

Haiku 只有延伸思考，**沒有自適應思考**；這可能是它單位成本低的原因之一。

## 待追蹤
- 延伸思考的 token 計費方式（是否計入輸出）
- 與 Claude Code `extended-thinking` 設定的關係
- 最大思考預算上限
