# 擴散模型（Diffusion Models）

> 一類通過逐步去噪學習數據分布的生成模型；從隨機噪聲出發，反覆預測並去除噪聲，最終生成逼真的圖像、音頻等；DALL-E、Stable Diffusion、FLUX 等主流文生圖系統的核心技術。

## 基本概念
- **前向過程（加噪）**：對清晰圖像逐步添加高斯噪聲，直到變成純噪聲
- **反向過程（去噪）**：訓練神經網路預測並去除每一步噪聲，從噪聲重建清晰圖像

## 三種數學視角
1. **DDPM**（去噪擴散概率模型）：離散步驟，預測每步添加的噪聲 ε
2. **Score Matching**：預測得分函數（log 概率梯度），連續版本
3. **Flow Matching**（流匹配）：預測速度場（vector field），將噪聲分布「流」向數據分布

## 在潛在空間中運作（LDM）
現代主流做法：不在像素空間，而在 [[VAE]] 的**潛在空間**中進行擴散
- 優點：計算成本低（壓縮比約 8x），潛在空間更平滑、更有語義結構
- 流程：VAE 編碼 → 潛在空間擴散 → VAE 解碼 → 像素圖像

## 條件生成
- **文字條件**：[[CLIP]] 編碼 prompt → 透過 Cross-Attention 注入擴散模型
- **引導機制**：[[CFG]]（Classifier-Free Guidance）放大條件信號

## 主要模型
| 模型 | 特色 |
|---|---|
| DDPM（Ho et al., 2020） | 奠基工作 |
| LDM / Stable Diffusion | 潛在空間擴散，開源 |
| DALL-E 3（OpenAI） | 強文字理解 |
| FLUX | 最新架構，使用 Flow Matching + DiT |

## 與其他生成模型的比較
- vs GAN：擴散模型訓練更穩定（GAN 容易模式崩潰），但推理速度較慢
- vs VAE 獨立使用：擴散模型輸出更清晰（VAE 單獨使用有模糊問題）
