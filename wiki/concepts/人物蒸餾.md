# 人物蒸餾（Character Distillation）

> 用 Claude Code + GitHub Skill 提取特定人物（如 Naval Ravikant、Elon Musk）的公開訪談、著作與決策紀錄，建構具有其三層思維結構的 AI 顧問。

## 詳細說明
人物蒸餾不是讓 AI「扮演」角色，而是提取該人物的**思考方法與邏輯**，讓使用者能借用其思維框架分析自己的問題。

### 三層架構（金字塔）
| 層次 | 內容 | 例子 |
|------|------|------|
| **頂層：表達方式** | 說話風格、語言習慣 | 幽默感、專業術語使用 |
| **中層：認知與決策規則** | 面對抉擇時的判斷標準 | 判斷投資機會的原則 |
| **底層：價值模型** | 看待世界的底層邏輯 | 馬斯克的[[第一性原理]] |

## 關鍵特徵 / 組成
- 工具：[[Claude_Code]] + GitHub Skill（Queen Skill）
- 資源消耗：一個人物約 15 分鐘、大量 Token，建議一次安裝一個
- 數據來源：公開訪談、書本著作、公司會議紀錄、決策歷史

## 與其他概念的差別
- 跟一般 Role-play Prompt 的差別：蒸餾提取底層價值模型，不只是表面的說話風格
- 跟 [[RAG]] 的關係：蒸餾是靜態提取人物思維，RAG 是動態檢索外部文件

## 應用 / 實例
- Naval Ravikant 蒸餾：針對「辭職創業」問題，跳出二選一框架，從「建立資產」角度重新定義問題

## 爭議 / 未定論
- 冰山局限：公開資料只是冰山一角，一個人的潛在認知往往無法完全從公開數據提取
- 蒸餾品質取決於該人物公開資料的充裕程度
