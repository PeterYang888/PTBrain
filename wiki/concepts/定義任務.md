# 定義任務（Task Briefing）

> 把 AI 當「資深合夥人」而非「實習生」：給它目標、背景、素材、邊界與完成定義，而非逐步操作指令。AI 時代取代純 Prompt 技巧的核心能力。

## 詳細說明
模型能力大幅提升後，「Prompt 是地板，定義任務是天花板」——Prompt 是文字架構與精準度（文筆），定義任務是思考力與溝通力。AI 是「意圖的鏡子」：產出空洞，是因為任務定義本身空洞。擅長帶人交辦的管理者思維，在 AI 時代往往比純技術背景更吃香。

## 關鍵框架：五欄位（5 Columns）
1. **目標 Objective** — 成品要拿來幹嘛（決策導向而非只做分析）
2. **背景 Background** — 提供脈絡（營收、客群、定位…）
3. **素材 Material** — 限制範圍；找不到資訊就留白，不要編造
4. **邊界 Boundary** — 設「牆」：不准捏造數據、不要只有形容詞、政策禁區
5. **完成定義 Definition of Done** — 設 Checkpoint 與格式：先給 Markdown outline，確認後再展開

## 知識工作四階段
依 AI 處於「思考 / 探索 / 決定 / 執行」哪一階段給對應指令：思考階段讓 AI 反問把模糊變具體；探索階段叫 AI map options 列 trade-off。

## 與其他概念的關係
- 是 [[Agentic_Workflow]] 的人機介面層；用「完成定義」的 Checkpoint 減少 Token 浪費
- 呼應 [[理解成本]]：高手差別在動手前的「思考習慣」而非 Prompt 技巧
- 適用時機：需跑半小時或交付他人的產出；簡單查詢不需如此繁瑣
