# 前饋網路（Feedforward Network, FFN）

> 資料從輸入層單向流向輸出層、不循環的最基本神經網路結構：經過一層或多層「加權求和＋非線性變換」，最後輸出結果。

## 詳細說明
前饋網路是「一條從輸入到輸出的單向計算流水線」：把輸入（如三個詞的[[詞向量]]拼接成 900 維數據）送進網路，經過隱藏層的線性變換與[[激活函數]]，最後為詞彙表中每個候選詞輸出一個分數，再用 Softmax 轉成機率分佈（見 [[2026-08-22_詞向量到transformer_nlp演進]]）。

比起 [[N-gram]] 純粹的頻率統計，FFN 能靠訓練自動學到更複雜的規律，且輸入是帶語義關係的詞向量而非孤立符號，因此具備初步泛化能力——訓練時看過「養了一隻鸚鵡」，遇到語義相近的「養了一隻虎皮鸚鵡」也能給出合理判斷。

## 關鍵特徵 / 組成
- **固定窗口限制**：FFN 的輸入層尺寸是寫死的（例如只接收前 3 個詞的向量），超出這個窗口的資訊對模型來說就像從未出現過——這正是它在 NLP 早期被 [[RNN]] 取代的原因
- **在 Transformer 中的角色**：現代 [[Transformer]] 的每個 Token 位置後面都接一個 FFN，功能是「Token 自己關起門來做深加工」——與[[注意力機制]]的「Token 之間互相交談」互補
- **事實記憶的存放處**：研究顯示模型的事實記憶（如「巴黎是法國首都」）主要存在 FFN 的參數與激活模式中；ROME（Rank-One Model Editing）技術可對特定 FFN 權重做「手術式」修改

## 與其他概念的差別
- 跟 [[RNN]]／[[LSTM]] 的差別：FFN 只能看固定長度窗口，RNN／LSTM 靠隱藏狀態讀取任意長度句子——這是 NLP 演進史上的關鍵一步升級
- 跟 [[MoE]] 的關係：MoE 就是把 Transformer 裡的 FFN 拆成多個「專家」子網路，每個 Token 只路由到其中少數幾個，MoE 整個機制都建立在切分 FFN 之上

## 應用 / 實例
- 早期 NLP 猜詞模型：3 個詞 × 300 維詞向量 = 900 維輸入 → FFN 隱藏層 → Softmax 輸出下一詞機率
- 現代 LLM：Transformer 每層的 Attention 之後接一個 FFN block，交替堆疊數十層
