# Transformer

> 2017 年 Google 論文《Attention Is All You Need》提出的架構，用[[注意力機制]]取代循環結構，是當前所有大型語言模型的底層框架。

> 在完整技術主線中的位置見 [[LLM_原理]]。

## 一次前向運算的完整流程
1. **Tokenization**：文本 → 整數 ID（GPT 系列用 BPE，LLaMA 系列常用 SentencePiece）
2. **Embedding**：ID → 具語義特徵的高維向量（7B 模型常見隱藏維度 **4096**）
3. **[[位置編碼]]**：注入順序資訊，現代模型多用 RoPE
4. **[[注意力機制]]**：Token 之間交換資訊
5. **前饋網路（FFN）**：每個 Token 各自深加工
6. **殘差流**：把結果寫回主幹，反覆數十層
7. **輸出下一個 Token**，追加回輸入端，循環生成

## 兩大核心組件的分工
> 「注意力是 Token 之間互相交談、交換信息，那前饋網絡（FFN）就是每個 Token 關起門來獨自做深加工。」

- **[[注意力機制]]**：跨 Token 的資訊流動
- **FFN（Feed-Forward Network）**：單 Token 內的非線性變換。研究顯示模型的**事實記憶**（如「巴黎是法國首都」）主要存在 FFN 的參數與激活模式中；ROME（Rank-One Model Editing）即可對特定 FFN 權重做「手術式」修改，把「巴黎」改成「羅馬」

## 殘差流（Residual Stream）
比喻為一條**高速公路**：各組件從流中讀取資訊、把結果寫回，而**不覆蓋**原始資訊。

配套的穩定機制：
- **殘差連接**：源自 2015 年何愷明等人的 **ResNet**
- **層歸一化（Layer Norm）**：與殘差連接共同確保數十層深的網路不會數值爆炸或塌縮
- 現代演進：Post-norm → **Pre-norm**，並常改用更簡單的 **RMSNorm**

## 效率演進
| 技術 | 作用 |
|---|---|
| **GQA（分組查詢注意力）** | LLaMA-2 70B：64 個 Query Head 但僅 8 個 KV Head，壓縮 KV cache |
| **[[MoE]]** | 稀疏激活，總參數大但實際運算少 |
| **FlashAttention／稀疏注意力** | 降低注意力的 $O(n^2)$ 計算代價 |
| **投機解碼（Speculative Decoding）** | 加速推論階段 |
| [[激活函數]] | ReLU → GELU → **SwiGLU** |

## 已知限制
- **$O(n^2)$ 複雜度**：序列長度增加時注意力計算量平方成長
- **Lost in the Middle**：即便有 RoPE，模型對提示詞中段的處理仍不如開頭與結尾可靠
- **架構挑戰者**：Mamba 等狀態空間模型（SSM）在超長序列上被視為具天然優勢的替代方案

## 與其他概念的關係
- 是 [[神經網路]] 的進階架構之一，與 CNN、ResNet 並列；但獨佔了當前 LLM 的主流地位
- [[MoE]]、[[位置編碼]]、[[注意力機制]]、[[激活函數]] 皆為其組件層概念
- 基礎模型只被訓練來「預測下一個 Token」，對話能力與事實準確性靠後續 [[RLHF]] 等對齊階段補上
