# 500+ 小時 Claude Code 心得：5 件我希望早點知道的事

> 來源：[原始檔](../../raw/transcripts/2026-06-19_claude_code_500小時心得.md) · 頻道：JayLuxAI | AI 自動化（Jay）

## 一句話摘要
累積 500 小時實戰後的 [[Claude_Code]] 進階心法：優化 [[Context_工程|Context 管理]]、用 CLI 取代 [[MCP]]、並讓 Claude Code 與 [[OpenAI_Codex|Codex]] 分工，把單一工具升級成省 Token 的 AI 系統。

## 核心論點
- **Context 決定輸出品質**：採「漸進式載入（Progressive Loading）」只載入當下所需，節省 context window
- **先規劃後實作**：實作前要求 AI 給 **5 個方案**評估，確認方向再動手（呼應 Superpowers / Brainstorming Skill）
- **CLI 優先於 API 與 MCP**：CLI 輸出最乾淨、無冗餘 metadata；MCP 光載入背景就吃約 **4,300 tokens**（用 `/context` 可觀察），是 Token 效率最低的選項
- **雙工具互補**：Claude Code 負責「開發 / 架構」，Codex 負責「Debug / 既有代碼優化」
- **建的是 AI 系統，不是單一功能**：系統建好後可複用、持續工作，個人從執行者轉為系統管理者（呼應 [[AIOS]]）

## 值得引用的段落
> 「這不是一個單一功能，你在建構的是一個 AI 系統。建好之後它就能幫你持續工作，不需每次從零開始。」
