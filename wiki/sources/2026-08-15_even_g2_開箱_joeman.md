# 不能拍照反而更沒壓力！可以翻譯、導航、串聯本地AI的智慧眼鏡！Even G2開箱【Joeman】

> 來源：[raw](../../raw/transcripts/2026-08-15_even_g2_開箱_joeman.md) · [[Joeman]]

## 一句話摘要
[[Joeman]] 開箱 [[Even_Realities_G2]]：無鏡頭設計換來社交隱私與美觀，實測翻譯（35 種支援／29 種雙向中文）、導航、對話摘要等內建功能，並詳細記錄串聯本地 [[Claude_Code]] 的設定門檻與生產力應用。

## 核心論點
- 無鏡頭是刻意取捨：換來社交安全感（不被誤會偷拍）與纖細外型，代價是無法拍照錄影
- 觸控模組移至鏡腳＋捨棄喇叭，機身僅 36g，是「不夾頭」與高配戴率的關鍵
- EvenHub SDK 開放平台已有上百款社群應用（電子書、貪食蛇等），內建功能之外仍有擴充空間
- 串聯本地 Claude Code 是「殺手級應用」：語音下指令即可遠端操控電腦、監控 Agent 工作狀態
- 導航功能受限於僅支援 App 內建地圖、無法用於高速移動（開車/騎摩托車）

## 值得引用的段落
