# ComfyUI 基礎教學 Ep1：Desktop 桌面版上手

> 來源：[原始檔](../../raw/transcripts/2026-06-27_comfyui_基礎教學ep1.md) · 主講：黃正熙的大師廚房

## 一句話摘要
[[ComfyUI]] Desktop 桌面版（Beta）安裝上手教學：用節點式工作流 + [[Stable_Diffusion]] 在本機免費生圖；核心比喻是「節點像樂高積木、無需寫程式」。

## 核心論點
- **介面即框架**：ComfyUI / Forge / Invoke / Automatic1111 都是 SD 的不同操作介面
- **模組化節點**：可視化節點（Nodes）+ 連接線（Noodles），如樂高
- **安裝門檻降低**：Desktop 版取代命令列，全自動安裝
- **圖片內嵌工作流**：產出圖拖回介面即復原全部設定

## 關鍵規格與操作
- 版本 **ComfyUI Desktop 0.4.7 (Beta)**，支援 Windows / Mac
- 模型自 **[[CivitAI]]** 下載：選 **Checkpoint** 類型 + **SafeTensor** 格式
  - SD 1.5：**512x512**，示範 Realistic Vision 6.0 Beta1
  - SDXL：**1024x1024**，示範 Juggernaut 11
- 模型放 `/models/checkpoints`，放後到 **Edit → Refresh** 才能選
- 關鍵鈕：**Queue**（算圖）、**Export**（輸出工作流分享）
