# ComfyUI V8 整合包：解壓即用的多模態工具箱

> 來源：[原始檔](../../raw/transcripts/2026-06-27_comfyui_v8整合包.md) · 主講：黎黎原上咩

## 一句話摘要
2026 全新 [[ComfyUI]] V8 整合包，預裝圖像/視訊/語音/音樂多模態模型「解壓即用」；亮點是啟動器介面由智譜 GLM-5 以 [[Vibe_Coding]] 重寫——AI 輔助開發的實例。

## 核心論點
- **降低准入門檻**：「省心包」預裝多模態模型，解決下載與路徑配置障礙
- **多模態整合**：不只生圖，含視訊（LTX-Video）、口型同步（Infini-Talk）、語音克隆（千問 TTS）
- **啟動器即中樞**：驅動檢測、Git 版本回溯升級、代理設置、外置模型庫映射
- **Vibe Coding 實踐**：啟動器 UI 由 GLM-5 以氛圍編程重寫

## 關鍵規格與數據
- **底層**：Python **3.13**、PyTorch **2.10.0 + CUDA 13.0 (CU130)**；內核 V0.15.1→可升 V0.16.3
- **硬體**：NVIDIA RTX 20 / GTX 16（Turing）以上；記憶體 **16GB**↑
- **容量**：Large 預裝包壓縮 **271GB**、解壓 **328GB**（建議 SSD）
- 模型：視訊 LTX-Video-2R / 混元 Vide1.5；圖編 [[FLUX|Flux 2]] 系列 / 千問 image-edit 2.5；音動 千問3-TTS / ACEP1.5 / Infini-Talk / Sale
- 「大兔子圖標」啟動器；Sage Attention 加速；外置庫可映射到他碟/區網
