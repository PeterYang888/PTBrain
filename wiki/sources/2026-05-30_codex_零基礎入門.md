# Codex 零基礎入門｜非工程師也能快速上手

> 來源：[briefing](../../raw/transcripts/2026-05-30_codex_零基礎入門.md) · [[OpenAI]]

## 一句話摘要
OpenAI Codex 是非工程師也能用的本地端 AI 工具，透過 Plugins + Skills 系統整合 Gmail、Canva、AE，實現郵件分類、圖片去背、系統清理等自動化。

## 核心論點
- **Codex ≠ 只有開發者**：對話界面讓任何人都能驅動自動化，無需程式背景。
- **三種權限模式**：預設安全（橘色）→ 自動審核 → 完全存取（Full Access），由保守到激進。
- **Plugins = Type-C 標準接頭**：遵循 NCP 協議，讓 Codex 能接 OpenAI、Google、Canva 等不同平台。
- **Skills = 外置化 SOP**：把規則寫入結構化文件，確保 AI Agent 遵循固定行為而非每次臨場發揮。
- **關鍵應用**：Gmail 智慧辦公（分類/摘要/批次回覆）、AI 去背工具、磁碟 Shader Cache 清理、After Effects 水墨特效。

## 值得引用的段落
> 「NCP 呢，就是我們 AI 工具世界裡的統一街頭標準，有點類似 iPhone 以前還有自己的充電線，現在都換成 Type C 了。」
