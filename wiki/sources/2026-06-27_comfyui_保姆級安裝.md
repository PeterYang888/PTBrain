# ComfyUI 保姆級安裝教學：硬體門檻與 AIGC 入門

> 來源：[原始檔](../../raw/transcripts/2026-06-27_comfyui_保姆級安裝.md) · 主講：阿一（設計師）

## 一句話摘要
[[ComfyUI]] 全方位入門教學，從硬體門檻、虛擬記憶體優化到模型路徑與報錯排除——核心論點是「開源（[[Stable_Diffusion]]/Qwen）只要硬體達標就免費無限用、自由度拉滿」，但 VRAM 決定創作邊界。

## 核心論點
- **開源 vs 閉源**：閉源（Kling/Sora）方便但付費、自由度有限；開源硬體達標即免費無限、工作流自由度高
- **硬體決定邊界**：VRAM 大小決定能做生圖/編輯/影片
- **系統級穩定性**：虛擬記憶體設定是避免運行中內存崩潰的關鍵
- **工作流 + Manager**：節點搭工作流，Manager 自動修復缺失節點

## 關鍵規格與設定
- **VRAM 門檻**：生圖 **8G**↑、編輯 **12G**↑、影片 **16G**↑；A/I 卡僅生圖建議 **24G**↑，顯卡優先 NVIDIA
- **虛擬記憶體**：初始 **60G**、最大 **120G**
- **雲端**：RunPod 等，4090D 約每小時 **1 塊多人民幣**
- 整合包推薦「秋葉」版；必須解壓到 **SSD**；裝 **PyTorch**（N卡 CUDA / A·I 卡 DirectML）
- 核心模型三件套：**clip / 底模 Checkpoint / vae** 分類放對應資料夾
- 報錯用 **Manager → Install Missing Custom Nodes** 自動修復
