# ComfyUI 零基礎上手第01集：保母級教學

> 來源：[原始檔](../../raw/transcripts/2026-07-04_comfyui_零基礎ep01.md) · 主講：幻響工坊

## 一句話摘要
從零開始手動配置 Python 3.10.9 + Git + 虛擬環境（venv），在 Windows 本機搭建 [[ComfyUI]] 生態系統（含 Manager 插件管理），與既有 [[2026-06-27_comfyui_基礎教學ep1]]（Desktop 一鍵版）路線不同，走的是命令列手動安裝路線。

## 核心論點
- **相容性至上**：選 Python 3.10.9（非最新版）確保與所有 ComfyUI 插件/模型相容
- **虛擬環境隔離**：venv 防止不同模型的 Python 套件版本衝突
- **磁碟管理**：Python / Git / ComfyUI 全裝 D 槽，方便管理模型檔並省 C 槽空間
- **插件化管理**：裝完主程式後第一件事是裝 Manager，把節點維護視覺化

## 關鍵操作流程
1. Python 安裝：勾選「Add Python to PATH」，路徑 `D:\python3.10`
2. Git 安裝：路徑同樣設 D 槽
3. `git` 指令下載 ComfyUI 到 `comfyui` 資料夾
4. 建立虛擬環境 `v`，啟動後提示字元出現 `(v)`
5. 更新顯卡驅動 + 在虛擬環境裝對應 CUDA 套件
6. 啟動後存取 `127.0.0.1:8188`；ComfyUI 資料夾約 5GB
