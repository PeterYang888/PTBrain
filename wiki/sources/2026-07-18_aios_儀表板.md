# 3 個步驟，從 0 打造你的 AI 儀表板

> 來源：[原始檔](../../raw/transcripts/2026-07-18_aios_儀表板.md) · [[Jay_JayLuxAI]]

## 一句話摘要
以 [[AIOS]] 四層架構（Context / Skills / Connectors / Cadence）為地基，用 Claude Design 做原型、[[Claude_Code]]（Agent SDK）實作，把零散 AI 腳本整合成團隊可共享的視覺化儀表板。

## 核心論點
- **解決工具碎片化**：把自動化流程、資訊流與對話介面整合進一個儀表板，降低分頁/終端機切換的認知負荷
- **AIOS 是 Agentic Workflow 的地基**：寫 code 前先定義四層——記憶（Context）、技能（Skills）、外部連接（Connectors）、執行節奏（Cadence）
- **介面即產品**：Claude Design 出原型 → Claude Code 讀本地代碼庫實作，把腳本包裝成非技術人員能按的按鈕
- **從個人工具到團隊系統**：VPS 部署後升級為 24 小時運作、全團隊共享

## 關鍵細節
- **設計流程**：`claude.ai/design/` 選 template、切 prototype 模式 → Claude 介面 `+` → `link local code` → browse 選本地專案
- **技術棧**：前端 Vite + React + TS；後端 FastAPI + Claude Agent SDK；設計到可用約 10–15 分鐘
- **Cadence 排程**：用 Trigger.dev 等平台設定時觸發
- **自訂指令**：`/run-aios` 一鍵啟動儀表板
- **實測**：ME Plan 技能算出 3440 卡路里/237g 蛋白質，結果推播到 Telegram
- Connectors 範例：YouTube、Google Calendar、Obsidian、Telegram
