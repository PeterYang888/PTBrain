# Claude Code 人物蒸餾：讓巴菲特和馬斯克變成你的 AI 私人顧問

> 來源：[原始檔](../../raw/transcripts/2026-05-16_claude_code_人物蒸餾.md)

## 一句話摘要
「人物蒸餾」透過 Claude Code + GitHub Skill 提取特定人物（如 Naval、馬斯克）的三層思維結構（表達方式、認知規則、價值模型），讓 AI 跳出「二選一」框架提供真正有深度的決策建議。

## 核心論點
- 三層架構：頂層（說話風格）/ 中層（認知與決策規則）/ 底層（價值模型，如馬斯克的第一性原理）
- 安裝需要 GitHub Skill（Queen Skill）+ Claude Code，一個人物約需 15 分鐘、大量 Token
- 普通 AI vs 蒸餾 AI 差異：普通 AI 給「二選一」建議，Naval 蒸餾 AI 質疑前提，引出「建立資產」的核心問題
- 數據侷限性：公開資料只是冰山一角，蒸餾品質受限於人物公開資料的充裕程度
