# 多 AI Deep Research → Claude 裁決｜Prompt 組

> 來源：[原始檔](../../raw/notes/2026-07-16_多ai研究裁決_prompt組.md) · 使用者自寫的方法論筆記（非外部文章）

## 一句話摘要
一套四段式 prompt 組：讓 Gemini / ChatGPT / Grok 三家 deep research 平行研究同一主軸、各自側重自己最強的資料源，最後把三份報告交給 Claude 做裁決仲裁——設計用途是 slot 競品研究等需要交叉驗證的決策型研究。

## 核心論點
- **差異化分工，不是三倍重複**：三家問同一主軸（方便交叉比對），但各自側重強項——[[Google|Gemini]] 負責廣度掃描＋官方一手數據＋學術/專利；[[OpenAI|ChatGPT]] 負責機制拆解＋設計邏輯＋因果鏈深挖；[[xAI|Grok]] 負責社群情緒＋論壇實戰＋即時動態（X / Telegram / Discord / Reddit / SEA 在地論壇）。
- **統一輸出格式是交叉比對的前提**：四段式（核心結論 3–7 條、逐條證據＋來源＋信心、反方觀點與不確定性、完整來源清單），內嵌在每個 prompt 裡。
- **Claude 是「裁判，不是總結者」**：Prompt D 要求七項裁決——共識（≥2 份獨立印證）、矛盾逐一裁決（⚠️ 用證據品質判，不用票數）、獨有洞見、三份共同盲點、證據品質稽核（點名幻覺引用/帶風向）、最終結論（每條附 falsification 條件）、建議下一步（回頭叫哪家補強）。
- **防幻覺鐵則內嵌每個 prompt**：不編造來源、查不到就寫查無、區分「已證實 vs 廣泛流傳」、單一來源主張標「待驗證」——與 PTBrain 自身的零信任資料原則同構。
- **任務參數五欄位填一次三家共用**：研究主題／決策脈絡／最終要做的決策／時間範圍／市場地區——與 [[定義任務]] 的五欄位 Task Briefing 法同構，皆以「決策」為研究錨點。

## 值得引用的段落
> 「三家問同一個主軸（方便交叉比對），但各自側重自己最強的資料源（避免產出重複、擴大覆蓋）。」— 設計原則

> 「你是這次多來源研究的『裁判』，不是總結者。」「⚠️ 用證據品質判，不要用票數。兩份弱報告不該壓過一份強報告。」— Prompt D

> 「每條附一個 falsification 條件：『要推翻這條，需要看到什麼證據？』」— Prompt D 最終結論

## 已填範例（slot 競品研究）
研究 Pragmatic Play《Gates of Olympus》tumble + multiplier 機制為何在東南亞長期霸榜：Gemini 挖官方 RTP 變體與市場榜單、ChatGPT 拆 tumble×multiplier 的 RTP 組成與數學、Grok 撈 SEA 玩家對波動度的真實吐槽與打法，Claude 對齊三者、裁矛盾、補盲點，最終決定新遊戲的 multiplier 曲線與 volatility 定位。
