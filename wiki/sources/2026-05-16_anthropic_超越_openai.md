# Anthropic ARR 歷史性超越 OpenAI

> 來源：[原始檔](../../raw/transcripts/Anthropic_超越_OpenAI_transcript.md)

## 一句話摘要
2026 年 4 月 7 日，Anthropic ARR 達 300 億美元正式超越 OpenAI 的 240 億，15 個月內 30 倍成長，靠的是 B2B API 商業模式而非消費者訂閱。

## 核心論點
- Anthropic 以 B2B API 為主（80% 企業收入），對比 OpenAI 的消費者訂閱（Netflix 模式），商業基因根本不同
- 1,000 個企業客戶每年付超過 100 萬美元，且過去 2 個月翻倍
- 成功四要素：Claude Code 開發者生態、安全品牌降低企業門檻、AWS/Google 算力聯盟、客製化專用模型
- 爭議：OpenAI 指出 Anthropic 以「總額（Gross）」計算 AWS/Google 通路收入，核心收入可能僅 40 億

## 值得引用的段落
> 「OpenAI 像 Netflix，靠用戶月費；Anthropic 則像 SaaS，直接把 AI 能力賣給企業。」

## 擴充細節

### ARR 時間軸
| 時間 | ARR | 重大事件 |
|---|---|---|
| 2025-01 | $1B | 起航期 |
| 2025 中 | $5B | Claude 3 系列推出 |
| 2026-Q1 | $27B | 企業 API 大爆發 |
| 2026-04-07 | **$30B** | 首次超越 OpenAI（$24B） |

### 成功四要素
1. **Claude Code 開發者佔領**：所有大公司的 Cursor 替代品
2. **Safety 招牌**：企業 IT 採購門檻更低（「AI 安全」的心理護城河）
3. **API 鏈完整**：AWS + Google + SpaceX 三家算力覆蓋，彈性不限量
4. **客製化專用模型**：9 大企業的 Cyber 痛點解決方案

### 商業模式對比
- **Anthropic** = SaaS / B2B，直接把 AI 能力賣給企業（類比 Salesforce）
- **OpenAI** = 消費訂閱，靠用戶月費（類比 Netflix）

### 爭議點
- OpenAI 反駁：Anthropic 把 AWS / Google Cloud 購買 Claude 的收入計為 Gross
- 若改以 Net 計算，爭議數字接近 $5B（不是 $30B）
- Anthropic 立場：自己是 Principle（設定價格），因此算 Gross 合理
