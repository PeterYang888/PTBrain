# 多 AI Deep Research → Claude 裁決｜Prompt 組

> 可存進 PTBrain 的 `research-runs/<日期_主題>/00_brief.md`。
> 設計原則:**三家問同一個主軸(方便交叉比對),但各自側重自己最強的資料源(避免產出重複、擴大覆蓋)。**

---

## 使用方式(30 秒)

1. 先填一次下面的【任務參數】,把值貼進三個 prompt 開頭的 `【貼上…】` 欄位。
2. Gemini / ChatGPT / Grok 各自**開 deep research 模式**,貼對應的 prompt,三家平行跑。
3. 三份報告下載 → 全部上傳給 Claude → 貼 **Prompt D** 做裁決。

> 每個 prompt 都已**內嵌輸出格式**,整段複製就能用,不用拼接。
> (代價:之後要改輸出格式,四個區塊要一起改;或把格式抽成你 vault 的一個 include。)

---

## 任務參數(填一次,三家共用)

- **研究主題**:
- **決策脈絡**(為什麼研究、要解什麼):
- **我最終要做的決策**:
- **時間範圍**(例:近 12–24 個月為主):
- **市場 / 地區**(例:菲律賓、印尼、泰國、馬來西亞):

## Prompt A —— Gemini Deep Research（廣度 × 官方一手 × 學術/專利）

```
【使用前:開啟 Gemini 的 Deep Research 模式】

你負責這次研究的「廣度掃描 + 一手數據」這條線。你的優勢是大範圍檢索、官方文件、
產業報告、學術與專利資料。請把火力放在把整個版圖攤開、抓到權威的一手來源,
不要在單一小點鑽太深(那條由別人負責)。

研究主題:【貼上研究主題】
決策脈絡:【貼上決策脈絡】
時間範圍:【貼上時間範圍】
市場/地區:【貼上市場】

你這條線優先回答:
1. 官方/一手事實:官方規格、RTP/波動度數據、provider 公告、認證(GLI 等)、
   專利、法規文件裡怎麼描述這件事?
2. 市場數據:市佔、營收、榜單排名、下載/活躍數據;產業媒體與報告
   (H2 Gambling Capital、EGR、SlotBeats、SBC News 等)怎麼說?
3. 學術/專利角度:有沒有相關的 game math、玩家行為研究、或專利佈局?
4. 全景地圖:主要玩家、機制變體、關鍵時間線、核心爭點——幫我畫出全貌。

【輸出格式(嚴格遵守,方便和另外兩份報告交叉比對)】
1. 核心結論(3–7 條,每條一句、可獨立驗證)
2. 每條的「證據 + 來源」:對應第幾條 / 證據重點(用你自己的話)/
   來源(出處名 + 網址 + 日期,只列你真的查到的)/ 信心(高·中·低,附一句原因)
3. 反方觀點與不確定性:有哪些證據和你相反?哪些地方你資料不足?
4. 完整來源清單:編號 + 標題 + 網址 + 日期 + 一句話標可信度(一手/二手/傳聞)
【防幻覺鐵則】不要編造來源或網址;查不到就寫「查無可靠來源」,不要生看似合理的連結;
區分「已證實」與「廣泛流傳」;單一且無法交叉驗證的關鍵主張,主動標「僅單一來源,待驗證」。
【語言】搜尋涵蓋英文與東南亞語系來源(別只查中文);報告以繁體中文輸出,
技術名詞、產品名、公司名保留原文。
```

為什麼這樣設計」講清楚,不用追求面面俱到的廣度(廣度由別人負責)。

## Prompt C —— Grok DeepSearch（社群情緒 × 論壇實戰 × 即時性）

```
【使用前:開啟 Grok 的 DeepSearch 模式】

你負責「玩家真實聲音 + 實戰與即時性」這條線。你的優勢是 X、論壇、社群的即時討論。
請把火力放在「真實玩家實際上怎麼說、怎麼玩、現在在吵什麼」——這是官方資料和
學術報告看不到的一面。

研究主題:【貼上研究主題】
決策脈絡:【貼上決策脈絡】
時間範圍:【貼上時間範圍】
市場/地區:【貼上市場;特別鎖定 SEA 在地社群:Telegram / Discord / Reddit / 本地論壇】

你這條線優先回答:
1. 玩家體感:玩家實際上怎麼評價?抱怨什麼、稱讚什麼?對波動度 / 公平性 /
   中獎體感的真實感受是什麼?
2. 實戰策略與 meta:玩家與實況主實際上怎麼玩?有哪些流傳的打法、下注模式、迷思?
3. 即時動態:最近有沒有相關爭議、病毒式討論、或風向轉變?現在正熱的是什麼?
4. 情緒定性:整體社群情緒偏正 / 負 / 分歧?哪一群玩家講的和哪一群不一樣?

【特別注意】社群來源可信度參差。務必區分「多人一致反映」和
「單一貼文 / 可能是行銷或帶風向」。明顯的傳聞、未證實的說法要標清楚。

【輸出格式(嚴格遵守,方便和另外兩份報告交叉比對)】
1. 核心結論(3–7 條,每條一句、可獨立驗證)
2. 每條的「證據 + 來源」:對應第幾條 / 證據重點(用你自己的話)/
   來源(平台 + 連結 + 日期 + 大概多少人這樣講)/ 信心(高·中·低,附一句原因)
3. 反方觀點與不確定性:有沒有相反的聲音?哪些地方樣本太少、無法確定?
4. 完整來源清單:編號 + 平台/貼文 + 連結 + 日期 + 一句話標可信度(多人一致 / 單一貼文 / 疑似帶風向)
【防幻覺鐵則】不要編造貼文或連結;查不到就寫「查無足夠社群討論」;
區分「已證實」與「流傳」;關鍵主張若只有單一來源,主動標「僅單一來源,待驗證」。
【語言】搜尋涵蓋英文與東南亞語系來源;報告以繁體中文輸出,技術名詞、產品名保留原文。
```

## Prompt D —— Claude 裁決（統整 + 邏輯辯論 + 最終結論）

```
【用法:把 Gemini / ChatGPT / Grok 三份報告當附件上傳(或整段貼上),再送出這段】

你是這次多來源研究的「裁判」,不是總結者。我有三份針對同一主題、
但來自不同資料源的 deep research 報告:
- Gemini:廣度掃描 + 官方一手數據
- ChatGPT:機制拆解 + 設計邏輯
- Grok:玩家社群聲音 + 實戰 / 即時

研究主題:【貼上研究主題】
我最終要做的決策:【貼上決策】

請產出以下裁決,全程繁體中文,技術名詞保留原文:

1. 共識(高信心)
   三份中有 ≥2 份「獨立來源」互相印證的點。註明是哪幾份、各自的來源類型
   (來源獨立性越高越可信)。

2. 矛盾點(逐一裁決)
   三份彼此衝突的地方。對每一個:攤開雙方說法 → 判斷哪邊證據更強、為什麼 →
   給出裁定,或明說「證據不足以判定」。
   ⚠️ 用證據品質判,不要用票數。兩份弱報告不該壓過一份強報告。

3. 獨有洞見(只有一份提到,但可能關鍵)
   只有單一報告提到、但對決策可能重要的點。標可信度,以及值不值得再查證。

4. 盲點(三份可能都漏掉的)
   以你對這主題的理解,三份共同的缺口或系統性偏差在哪?

5. 證據品質稽核
   點名任何可疑來源:無法驗證的連結、疑似幻覺引用、只靠單一來源的關鍵主張、
   或明顯的社群帶風向。

6. 最終結論
   - 對我的決策,綜合判斷是什麼(2–5 條)
   - 每條的整體信心:高 / 中 / 低
   - 每條附一個 falsification 條件:「要推翻這條,需要看到什麼證據?」

7. 建議的下一步(可選)
   若有哪個矛盾點值得回頭再叫某一家 AI 補強或反駁,列出來:要問誰、問什麼。
```

## 已填範例(照這個 flavor 填【任務參數】)

- **研究主題**:Pragmatic Play《Gates of Olympus》的 tumble + 隨機 multiplier 機制,為何能在東南亞市場長期霸榜
- **決策脈絡**:我們在設計一款同樣走 tumble + multiplier 路線的新 slot,想知道 GoO 成功的真正關鍵是數值設計、體感節奏、還是行銷/通路,以決定差異化該押在哪
- **我最終要做的決策**:新遊戲的 multiplier 數值曲線與 volatility 定位怎麼設,才能學到 GoO 的長處又做出區隔
- **時間範圍**:近 24 個月
- **市場 / 地區**:菲律賓、印尼、泰國、馬來西亞

> 填進去後你會看到三條線自然分岔:Gemini 去挖 GoO 的官方 RTP 變體與市場榜單、ChatGPT 去拆 tumble×multiplier 的 RTP 組成與數學、Grok 去撈 SEA 玩家對它波動度的真實吐槽和打法。Claude 再把三者對齊、裁矛盾、補盲點。
