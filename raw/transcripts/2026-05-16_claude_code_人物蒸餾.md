# AI 人物蒸餾技術簡報：建構專屬頂級顧問系統

## 執行摘要

本報告深入分析「人物蒸餾」（Character Distillation）技術，這是一種將特定人物的知識、經驗與思維邏輯轉化為 AI 私人顧問的先進方法。透過提取公開訪談、著作及決策紀錄，AI 能夠模擬如伊隆·馬斯克（Elon Musk）或納法爾·拉維康特（Naval Ravikant）等頂尖思想家的思考框架。本文件詳述了人物蒸餾的三層架構、實作流程、與一般 AI 的差異化表現，以及在實際決策中的應用價值。

---

## 核心概念分析

### 1. 什麼是「人物蒸餾」？
人物蒸餾的核心在於不僅僅是讓 AI「扮演」某個角色，而是透過大量數據提取該人物的思考方法與邏輯。其目標是讓使用者能利用這些名人的思維邏輯來分析問題，使 AI 成為真正的智慧顧問。

### 2. 人物蒸餾的三層架構模型
一個完整的人物蒸餾模型呈現金字塔結構，由底至上分為三個層次：

| 層次 | 內容定義 | 示例 |
| :--- | :--- | :--- |
| **頂層：表達方式** | 該人物的說話風格、平時使用的語言習慣。 | 幽默感、專業術語的使用。 |
| **中層：認知與決策規則** | 面對抉擇時的判斷標準、捕捉訊息的敏感度與反應方式。 | 判斷投資機會的原則。 |
| **底層：價值模型** | 看待世界的底層邏輯與基本價值觀。 | 馬斯克的「第一性原理」（First Principles）。 |

### 3. 技術實作與資源需求
實作人物蒸餾需透過 Claude Code 與技能插件（如 GitHub 上的 Queen Skill，後簡稱為「智囊團 Skill」）。

*   **安裝流程：** 複製 GitHub 連結後引導 AI 進行安裝，可自訂技能名稱與預設語言（如繁體中文）。
*   **資源消耗：** 安裝一個人物通常需要約 15 分鐘。此過程高度消耗 Token 與運算能量，建議一次僅安裝一個人物。
*   **數據來源：** 包含公開訪談、書本著作、公司會議紀錄及決策歷史。

## 案例研究：Naval 框架 vs. 普通 AI Agent

在針對「是否應辭職創業」的諮詢中：

*   **普通 AI Agent：** 提供相對平衡的二元選項分析，如驗證客戶需求、檢視存款預算、建議利用業餘時間測試等，但仍受限於「二選一」的思維框架。
*   **Naval 蒸餾 AI：** 跳出二選一的框架，直接質詢問題的前提。引用 Naval 的「合約」理論與「資產」定義，指出真正的核心在於是否在「建立資產」（即睡覺時也能賺錢的系統，如 SAS 網站、YouTube 頻道或忠實用戶群）。

## 關鍵語錄與上下文解析

> **「我們每一個選擇其實都是想跟我們自己簽一份合約。」**
*   **上下文：** 留在公司是與自己簽下「在獲得自由前保持不滿」的合約；創業則是簽下「在公司活下來前保持焦慮」的合約。重點在於你願意承擔哪種痛苦。

> **「真正正確的不是勇氣，是寬度。」**
*   **上下文：** 重點不在於是否有勇氣離開，而是在於你建立的資產（資產的類型與寬度）是否足以支撐你的目標。

> **「我們看到的只是冰山上面的部分，其實一個人可以成功，最重的那部分是冰山底下的部分。」**
*   **上下文：** 這是對人物蒸餾技術的警示。公開資料往往是經過包裝的產物，一個人內在的潛在認知往往無法完全透過公開數據提取。

## 實務操作指引與行動建議

### 1. 優化諮詢結果的關鍵步驟
*   **提供具體背景：** 必須提供詳細的現況資料，例如目前的經濟壓力、職位優勢、副業的具體進度。
*   **進行思維辯論：** 不要直接全盤接受建議。應針對 AI 給出的觀點進行反駁或補充資料，透過辯論確認決策是否能經得起推敲。

### 2. 應用建議
*   **識別思維盲點：** 利用不同人物的視角（如馬斯克 vs. 巴菲特）來審視同一個問題，找出自己思考不足的地方。
*   **輔助決策而非替代決策：** 蒸餾出的 AI 僅供參考。由於數據侷限性，它無法完全代表真人的複雜性，最終決策權仍應保留在使用者手中。

### 3. 使用注意事項
*   **數據品質連動性：** 蒸餾品質取決於人物公開數據的充裕程度。對於公開資料較少的人，使用者需自行提供更多相關資料餵養 AI。
*   **權限授權：** 在安裝過程中，需給予 AI Agent 建立 Skill 與搜尋網絡的權限。
