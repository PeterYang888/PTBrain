# 不能拍照反而更沒壓力！可以翻譯、導航、串聯本地AI的智慧眼鏡！Even G2開箱【Joeman】

## 一句話摘要
Even G2 智慧眼鏡砍掉鏡頭與喇叭模組以重塑美感與社交隱私，並透過開放的 EvenHub SDK 與本地 AI 代理（如 Claude Code）串聯，將智慧眼鏡打造成隨身控制與資訊顯示終端。

## 主講者背景
- 主講者：Joeman（九妹），台灣知名科技與豪華產品開箱 YouTuber。
- 講述風格親切、務實且注重使用者體驗，擅長從「社交心理學」（防偷拍警覺心）與「生理配戴感」（重量、夾頭問題）切換視角剖析硬體。

## 核心論點
- **「無鏡頭」重塑社交安全感**：傳統智慧眼鏡的鏡頭常引發偷拍疑慮，讓周遭人緊張。Even G2 移除鏡頭模組，消除社交壓力、可自由進出機密隱私場合，換來纖細美觀外型。
- **極輕量化與不夾頭設計**：觸控模組移至鏡腳、捨棄喇叭與鏡頭，機身重量降至 36 克，大幅提升日常配戴率。
- **出色的開箱即用功能**：透過左右兩塊光學波導鏡，直接投影看板、即時名詞解釋、語音提詞與雙向翻譯等實用資訊。
- **開放平台帶來無限擴充性**：官方推出的 EvenHub SDK 開放平台吸引社群自主開發非官方應用（電子書、貪食蛇等），打破功能局限。
- **串聯本地 AI 代理（殺手級應用）**：與電腦本地的 AI（如 Claude Code）對接，讓眼鏡直接變身為下達指令、遠端遙控並監控 AI 工作流的移動終端。

## 關鍵細節與數據
**外觀與設計規格**：
- 重量 36 克（比一般眼鏡重約 12 克，比 Meta 智慧眼鏡輕 15 克）
- 設計師：邀請德國高階眼鏡品牌 MYKITA 共同創辦人 Filip Hoffman 親自設計
- 款式：「復古圓形」與「俐落方形」2 種框型；「綠色」「棕色」「灰色」3 種顏色
- 觸控模組位於鏡腳（而非鏡腿），鏡腿維持纖細金屬設計；內建收音麥克風，但移除喇叭與骨傳導發聲裝置（無法聽音樂）

**功能與實測表現**：
- 看板畫面（Dashboard）：可自定義顯示時間、新聞、股價與行事曆
- 對話功能（Dialogue）：即時轉寫＋專有名詞點選解釋，結束後自動生成逐字稿與摘要，收音準確度實測約 90%
- 提示功能（Teleprompter）：顯示文案，支援語音偵測自動捲動，幾乎無須手動控制
- 翻譯功能：支援超過 35 種語言，其中 29 種（含斯洛伐克文等歐美語系）可與中文即時雙向翻譯
- 導航功能：鏡片顯示方位與地圖，僅「走路」與「騎行（腳踏車限定，不適合摩托車/開車，GPS 略有延遲）」2 種模式，僅支援 App 內建地圖，不支援第三方地圖
- EvenAI：基本語音助理，資料搜尋不到 1 秒；因無相機，無法詢問「眼前物體是什麼」

**EvenHub 開發者平台**：
- 已累積上百款非官方 App（AI、娛樂、教育、健康等）
- 電子書功能：支援導入小說文檔，可設定閱讀速度自動翻頁
- 小遊戲：可在眼鏡上玩「貪食蛇」

**本地 AI 串聯設定細節**：
- 電腦端需安裝 Claude Code CLI 工具與 Node 環境，透過官方 Even Terminal 連線
- 免費版 Claude 帳號不支援連線，必須訂閱 Pro 以上，或使用 API 計量付費的 Console 帳號
- 實測：對眼鏡說「幫我開啟 Chrome 或 Spotify」可自動執行；可寫規則指令，泡咖啡時語音呼叫「打開工作用 APP」，AI 自動開好 Slack、Spotify、Chrome 並加載股票大盤網頁；亦可語音命令 AI Agent 遙控剪輯端影音、自動過濾毛片

**配件 - 智慧戒指 Even R1**：
- 外層氧化鋯陶瓷（抗刮、抗腐蝕），IP68 防水等級
- 可聯動控制 Even G2（無須抬手摸鏡腳），並在眼鏡內新增「健康」小工具，追蹤心率、溫度、血氧、睡眠品質與卡路里，並計算一整天的生產力分數

## 重要引言
> 「是不是我們開場不特別講的話，大家可能不會發現它是智慧眼鏡。」

> 「設計方向其實相當的正確，畢竟智慧眼鏡本體還是眼鏡，你總是要讓人願意天天帶著，再來加入其他功能。」

> 「等我拿著咖啡回到電腦前時，它就會幫我自動開好 Slack、Spotify、Chrome……這是我認為智慧眼鏡最符合我們對於未來想像的使用方式，不但方便而且非常科幻。」

> 「這對應走路或腳踏車的慢速移動還可以，但如果是開車或騎摩托車就比較不適合了。」

## 與其他 AI 工具/概念的關聯
- **Claude Code 與本地 AI 代理**：Even G2 將自己定位為 Claude Code 的移動終端機，用戶可一邊走動、泡咖啡，一邊監控電腦上 AI 代理的執行狀態。
- **Meta / 小米智慧眼鏡對比**：Even G2 選擇完全相反的去相機、去發聲路線；Meta 偏向戶外內容創作與第一視角拍攝，Even G2 偏向辦公、閱讀、即時輔助與隱私至上的極客工作流。
- **低頭族健康**：抬頭視角（HUD Display）將部分手機功能解放，未來可能減少頸椎/腰部代償傷害。
