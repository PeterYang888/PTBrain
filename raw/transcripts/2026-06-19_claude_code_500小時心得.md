這部影片由「JayLuxAI | AI 自動化」頻道提供，分享了主講者在累積 500 小時實戰經驗後，關於 Claude Code 的進階使用心法與避坑指南。以下是詳細的 Briefing：

### 1. 一句話摘要
透過優化 Context 管理、善用 CLI 替代 MCP 以及工具間的分工協作，將 Claude Code 從單純的程式工具轉化為高效、省 Token 的 AI 自動化系統。

### 2. 主講者與背景
*   **主講者**：Jay。
*   **背景**：科技創作者，經營「JayLuxAI | AI 自動化」頻道。專注於 AI 系統建構與企業自動化流程（Agentic Workflow），在 Claude Code 剛推出不久便投入大量時間進行專案開發實測 [1, 2]。

### 3. 核心論點（條列重點）
*   **Context 是輸出的核心**：Claude Code 的精準度完全取決於上下文（Context）的質量，應採用「漸進式載入」策略以節省 Context Window [1, 3]。
*   **先規劃後實作（Plan before Action）**：直接下指令容易導致方向偏差，應先要求 AI 提供多個實作方案，確認後再執行 [3, 4]。
*   **大型專案善用 Superpowers**：透過 Brainstorming 等特定技能（Skill）引導 AI 以「開發者」思維進行深度規劃，而非僅是「使用者」的簡單指令 [4]。
*   **CLI 優先於 API 與 MCP**：CLI 提供最純粹的文本輸出，能極大化節省 Token 並避免不必要的元數據（Metadata）消耗 [5, 6]。
*   **雙工具互補機制**：利用 Claude Code 進行新功能的「開發」與「架構」，而將「Debug」與「現有代碼優化」交給表現更穩定的 Codex [6, 7]。

### 4. 關鍵細節與數據（務必保留具體數字、CLI 指令、程式碼片段、工具名稱、設定範例）
*   **關鍵設定檔**：
    *   **`.claudmd`**：存放在專案根目錄的設定檔，用於定義開發偏好、限制條件及特定狀況的處理邏輯 [1]。
*   **數據與比較**：
    *   **MCP Token 消耗**：在 Claude Code 中輸入指令 `/context` 可以觀察到，MCP tools 即使在未開始任務前，僅載入背景資訊就可能消耗約 **4,300 個 tokens** [6]。
    *   **方案評估數量**：建議在實作前要求 AI 提供 **5 個不同實作方案** 進行評估 [3]。
*   **工具與指令**：
    *   **CLI (Command Line Interface)**：推薦作為 Agent 時代的最佳溝通媒介，因其輸出最「乾淨」且無需額外解析 JSON 物件 [5, 6]。
    *   **Superpowers / Brainstorming Skill**：強迫使用者將模糊想法轉化為清晰計畫（Plan）的關鍵功能 [4]。
*   **Context 管理方法**：
    *   **Progressive Loading（漸進式載入）**：僅載入任務當下所需的資料，避免浪費資源在不相關的資訊上 [3]。

### 5. 重要引言或例子
*   **核心引言**：「這不是一個單一功能，你在建構的是一個 AI 系統。建好之後它就能幫你持續工作，不需每次從零開始。」 [2, 7]
*   **實務案例**：主講者展示使用 **Miro** 或 **Excalidraw** 畫出系統（如 AIOS）的 Agent、Memory 與 Productivity 區塊，並將已完成的開發項目標註為綠色，再交由 AI 根據此架構執行 [4]。
*   **API 的缺點**：呼叫 API 時會回傳大量 `JSON`、`Metadata`、`status codes` 等冗餘資訊，這每一項都會被算作 Token 並塞入 Context [5, 6]。

### 6. 與其他 AI 工具/概念的關聯
*   **Codex**：被定位為「Debug 專家」，其思考方式與 Claude 不同，能快速找出 Claude 繞不出的 Bug 或針對現有 Code 進行 Review [6, 7]。
*   **MCP (Model Context Protocol)**：雖然是強大的插頭（Plug），但被列為 Token 消耗效率最低的選項（第三名），次於 CLI 與 API [5, 6]。
*   **AI OS (AI 操作系統)**：這套心法最終指向建立一個可複用的 AI 系統架構，讓個人能從執行者轉向管理與升級系統的角色 [2, 4, 7]。
