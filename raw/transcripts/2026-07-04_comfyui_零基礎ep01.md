# ComfyUI 零基礎上手第01集：保母級教學

## 一句話摘要
本教學指導用戶如何從零開始，透過手動配置 Python 3.10.9 環境、Git 版本控制與虛擬環境（venv），在 Windows 本機端搭建一套具備 Manager 插件管理功能的 ComfyUI 生態系統。

## 頻道/主講者背景
主講者來自 YouTube 頻道「幻響工坊」，專注於提供 AIGC 相關的「保姆級」教學，強調從空白電腦開始的實作引導，幫助非技術背景用戶掌握 AI 工具的底層安裝邏輯。

## 核心論點
- **相容性至上**：選擇 Python 3.10.9 而非最新版本，是為了確保與目前所有 ComfyUI 插件及模型的最高相容性，避免安裝過程中出現無法預期的報錯。
- **環境隔離（虛擬環境）**：強調必須建立虛擬環境（venv），以防止不同 AI 模型間因 Python 套件版本不一而產生衝突，這是維持系統穩定運行的關鍵。
- **磁碟管理策略**：建議將 Python 環境、Git 工具與 ComfyUI 本體全部安裝在 D 槽（非系統槽），以便未來管理龐大的模型檔案並節省 C 槽空間。
- **插件化管理思維**：安裝完主程式後的首要任務是安裝 Manager（管理器），這能將複雜的節點與套件維護轉化為視覺化的管理介面。

## 關鍵細節與數據
- **軟體版本與規格**：Python 3.10.9（Windows 64-bit）；Git（Windows 對應版本）；本地存取位址 `127.0.0.1:8188`。
- **具體操作與 CLI 指令流程**：
  1. Python 安裝：下載後務必勾選「Add Python to PATH」，自定義路徑至 `D:\python3.10`
  2. Git 安裝：同樣建議路徑設於 D 槽，其餘選項保持預設「下一步」即可
  3. ComfyUI 下載：在 D 槽根目錄輸入 CMD 開啟命令提示字元，用 `git` 指令將程式碼下載至名為 `comfyui` 的資料夾
  4. 建立虛擬環境（venv）：在資料夾內執行 Python 指令，創建名為 `v` 的虛擬環境資料夾
  5. 啟動虛擬環境：進入虛擬環境目錄，看到提示字元出現 `(v)` 標記，代表環境切換成功
  6. GPU 支援安裝：更新顯卡驅動至最新版後，在虛擬環境中安裝顯卡對應的 CUDA 相關套件
- **系統體積**：完成初步環境與套件下載後，ComfyUI 檔案夾大小約為 5GB 左右。

## 與其他 AI 工具/概念的關聯
- **Workflow Automation（工作流自動化）**：ComfyUI 採用基於「節點」的自動化邏輯，本教學完成後，用戶將能透過 Manager 管理器進一步操作複雜的 AIGC 工作流與節點。
- **Stable Diffusion（SD）**：ComfyUI 是 SD 的另一種操作介面（對標 WebUI），其底層依賴 PyTorch 與顯卡運算，本安裝流程實質上是在為高效能的 AI 繪圖任務佈置底層算力環境。
- **Git 版本控制**：展示了 AI 開發者生態中如何透過 git 進行套件的快速同步與版本回溯，這在安裝 custom_nodes（自定義節點）時尤為重要。
