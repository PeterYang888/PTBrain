# FLUX.2 Klein 百科全書：性價比文生圖/編輯模型

## 一句話摘要
FLUX.2 Klein (CL) 是黑森林實驗室於 2026 年發布的輕量化統一性模型，能在單一文件中實現極速文生圖、精確圖像編輯與多圖參考組合，被譽為 AIGC 領域的「性價比小鋼砲」。

## 頻道/主講者背景
主講者來自 YouTube 頻道「黎黎原上咩」，專注於 ComfyUI 整合包的開發與維護（如 V8 版本），並提供深度模型評測、工作流優化與 AIGC 實作教學。

## 核心論點
- **高度整合的統一性模型**：不需切換多個文件，即可同時處理高質量文生圖、單圖編輯（換裝、變換視角、修復老照片）及多圖素材組合。
- **圖像編輯是真正的「舒適區」**：相較競爭激烈的文生圖，CL 在圖像編輯上競爭力極強，能精準描述「變化」而非僅「內容」，且顯存佔用低於千問等重型模型。
- **推薦 9B 蒸餾版**：實測 9B 蒸餾版在效果、細節、多樣性上遠優於 4B 與 9B 基礎版，更適合開箱即用。
- **採樣步數與速度的極致平衡**：作為蒸餾模型，僅需 4–6 步即可產出細節豐富的圖像，速度快到能在競品出一張圖的時間內多次「抽卡」優化。
- **語言理解與局限**：具備中文理解，但複雜長提示詞英文輸入更穩定；在複雜空間關係與人體解剖（如手指）仍有出錯機率。

## 關鍵細節與數據
- **發布商與版本**：黑森林實驗室 (Black Forest Labs)，2026 年 1 月發布；分 **9B** 與 **4B**，各有基礎版與蒸餾版。
- **格式與大小**：9B 蒸餾版 BF16 完整版 **18.2G**（建議 12G 顯存）；FP8 版 **9.43G**（支持 6G 顯存）；NVFP4 版 5.76G（僅 NVIDIA Blackwell/50 系列優化）。
- **軟體環境**：ComfyUI 內核需 **V0.9.2** 以上（演示用 V0.14.1）；文本編碼器 9B 搭千問 3-38B、4B 搭千問 34B。
- **出圖性能**：本地 4080 顯卡生成 720x1280，錄製狀態約 **13 秒**、非錄製約 **5 秒**；最佳像素約 **100 萬像素**（1024x1024 或 720x1280）。
- **推薦採樣參數**：步數官方 4 步、主講者建議 **6 步**；**CFG 固定為 1**；採樣器/調度器建議 **Euler + Simple**。
- **多圖參考**：實測建議同時輸入不超過 **4 張**。

## 值得引用的金句
- 「競品出一張圖的時間，CL 可能已經抽了十幾次卡了。」——強調極速出圖帶來的迭代優勢。
- 「圖像編輯的提示詞核心思想就一個：描述變化而非內容。」——點出操作編輯模型的關鍵思維轉變。
- 「能不用 4B 模型就盡量不用吧。」——基於實測 4B 容易出現多餘肢體等錯誤的直白建議。

## 與其他 AI 工具/概念的關聯
- **ComfyUI Workflow**：CL 運作拆解為模型加載、提示詞/尺寸設置、採樣/調度、圖像解碼/保存四個標準化模組。
- **千問 (Qwen)**：直接採用千問系列作為文本編碼器（38B/34B），語義理解基礎強大。
- **SDXL Turbo / Image Turbo**：人像生圖上 Image Turbo 皮膚質感較強，但 CL 在藝術表現力與構圖多樣性更優。
- **Workflow Automation**：整合 GLM-4 等 LLM API 自動擴展提示詞，配合 multiangle 插件做視覺化視角控制。
